# Spec: OmniPhysics Phase 1 MVP

## Requirements
- Index-finger tracking via webcam at 60 FPS (640x480 input resolution).
- Pinch gesture detection (thumb tip to index tip distance threshold) to toggle draw mode.
- Render an interactive 3D physics scene (Three.js sphere/pendulum) with Raycaster line drawing.
- Scaffold FastAPI endpoint /api/chat with streaming responses for physics explanations.
